# Avi Team Quickstart

Avi is CALATRAVA's Slack teammate for HR. Use Avi in the dedicated HR Slack
channel when you want help understanding the product, talking through an
improvement, or preparing a code change for review.

## Start a conversation

Mention `@Avi` in the dedicated HR Slack channel to start a new thread. After
that, keep replying in the same thread. You do not need to mention Avi again in
each follow-up.

Example:

> `@Avi Where can I see who still has onboarding tasks left?`

> `I mean after someone has already started.`

## Ask product questions

Use Avi for questions about how CALATRAVA works today.

Example:

> `@Avi What happens after a candidate is moved to onboarding?`

Avi should answer in plain language based on the current product and, when
helpful, include compact links to the current source so the answer can be
verified.

## Suggest an improvement

Use the thread to describe friction, gaps, or ideas. Brainstorming with Avi is
just a discussion. It does not start a build by itself.

Example:

> `It takes too many clicks to check onboarding progress. Could this be simpler?`

You can keep talking through the problem, ask follow-up questions, or compare
options before deciding whether you want a change prepared.

## Request a build

When you want Avi to prepare a concrete change, ask for a build clearly in the
thread.

Example:

> `Please build that change and prepare it for review.`

The result is a draft pull request for human review. Avi does not automatically
merge or deploy changes.
